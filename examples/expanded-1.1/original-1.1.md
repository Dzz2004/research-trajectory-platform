### 1.1 Agent 应完成什么

从用户给出的光催化产氢体系与研究目标出发，重建已有结构和可能的作用过程，识别损失与知识缺口，比较增强机制及材料，再根据材料的限制检查已有结构可以承担哪些辅助功能，最后选择具有物理依据、符合结构边界且可验证的材料组合与空间构型。

本项目希望重点检验以下推导：

**研究目标 → 现状与损失 → 增强方向 → 主功能材料 → 材料限制 → 辅助功能需求 → 已有结构的承担能力 → 剩余缺口 → 实现路线 → 空间构型 → 条件性结论与验证方案。**

其中，“已有结构能否帮助解决新增材料的限制”是必须认真执行的分析，不应只把已有结构当作一个被动放置材料的支架。

具体实验设计思路为：WO3:Yb,Er可以将CdS无法利用的近红外光转换为可用的可见光，光子晶体可以将光聚焦在需要的部位进一步提高上转换效率。贵金属的LSPR效应可以通过局域电场增强来增强光发射，但响应波段与尺寸有关，响应强度与距离有关，对Au来说，如果希望增强550nm左右CdS可用的波段的发射，尺寸应该在15nm左右，但Au在溶液中易发生团聚，光子晶体内有有序大孔，当Au附着于孔壁时，不但可以使其与稀土发光中心的距离可控，还可以为其提供相对稳定的环境，抑制其烧结，最终目标为从基础样品（WO3:Yb,Er光子晶体+CdS）提出改进策略，人为选择LSPR效应辅助并将材料固定为Au，最终推导得到Au以均匀尺寸附着于WO3光子晶体的孔壁上的结构。
